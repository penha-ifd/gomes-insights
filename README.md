# Gomo Insights

Repositório de inteligência do Gomo Agent. Atualizado automaticamente via cron.

## Estrutura
- `radar/` — Radar diário (métricas + mercado)
- `trends/` — Séries temporais em JSONL (DAU, WAU, Reviews)
- `decisions/` — Decisões e discussões do canal #gomo-insights

## Agente
Gerenciado por @gomo_agent no Slack.
